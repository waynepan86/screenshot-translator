# 截图工具 · Screenshot Translator

Windows 桌面截图、后台小幅纠偏、在线翻译与原位显示。当前版本 **1.10.2**。

## 1.10.2 覆盖与工具栏改进

- 扩大字形框外的擦除范围，减少行内代码底框残留。
- 对平滑背景按整段重建，使用四边渐变插值并检查空白区域；整段连续合成，减少逐行修复接缝。
- 工具栏改为白底、深色图标、细边框与柔和阴影；调整按钮强调色，并补充打码矢量图标。

## 1.10.1 原位显示修复

- 背景修复始终从原图取样，所有文字擦除完成后再统一绘制译文，避免后续文字块擦掉或污染已绘制译文。
- 擦除区域避开相邻文字块，包括未翻译及主动恢复的原文。
- 大标题允许较宽行距合并，减少标题被拆成半句翻译；大字号译文放不下时允许继续适度缩小。

## 1.10.0 改进

- 后台纠偏按片段保护变量、路径、数字与标识符，不再因正文包含变量而跳过整行；自动修改仍要求两次图像重识别一致，且限制修改幅度。
- 修复换行连字符被一律删除的问题，保留 `non-root` 等复合词；保留译文主动换行、原文行距和标签左侧位置。
- 修复行内代码块将句子拆开、片段顺序错乱与空格粘连的问题，连续相邻片段按同一行重新合并。
- 截图编辑中点击“贴图”或按 F3，将当前原图或译文独立置顶；支持拖动、滚轮缩放、Ctrl+滚轮透明度、空格查看原图、右键复制及双击关闭。
- 增加遮盖打码，拖动填充不透明色块，支持撤销、复制和保存。
- 区域截图时悬停高亮窗口，单击选择窗口，拖动仍为手动框选；窗口坐标按显示器缩放转换。

## 1.9.1 修复

- 翻译完成后直接原位显示，不再自动弹出文字复核面板；移除复核设置，纠偏自动在后台完成。
- 修复包含行内代码、环境变量和文件名的正文被拆成多个翻译块的问题。
- 完整文字行统一擦除，对平滑渐变背景重建底色，减少残字和行内代码底框残留。

## 使用

- F1 框选截图，F2 全屏截图；快捷键可在设置中修改。
- 工具栏“翻译”完成 OCR、复核、翻译和原位排版；“复原”切换原图。
- 在截图窗口按住空格临时查看原图。
- F3 或点击“贴图”，让截图或译文独立置顶。
- 文字面板提供原始识别、可编辑的复核结果、完整译文；支持逐块重译、恢复及复制。
- Enter 确认到剪贴板，Esc 取消，Ctrl+Z 撤销标注。
- 托盘右键 → **使用说明**，打开应用内离线帮助。

详细操作见 [使用说明](USER_GUIDE.md)。文中的快捷键占位符会在应用内替换为当前设置。

## 翻译服务与配置

支持 DeepL、Azure、OpenAI 兼容大模型、百度、有道及 Google / MyMemory 备用链路。在设置中选择引擎、填入对应凭据并测试。

本地 OCR 及复核不上传截图。在线翻译发送识别文字，DeepL 还会收到当前截图的相关文字作为上下文。首选引擎失败时可能改用备用服务，界面会标明。

`config.json` 保存设置与密钥，**不应提交到版本库**。源码运行时位于项目目录；打包版位于 exe 同目录。更新时保留自己的配置文件。本仓库与发布包不含个人密钥。

## 开发与打包

建议 Windows 10/11、Python 3.11–3.13。

```powershell
python -m pip install -r requirements.txt
python main.py
```

RapidOCR 首次准备模型可能需要网络，模型就绪后识别可离线运行。Windows OCR 是备用引擎，受系统语言包影响。本地复核默认开启，每次最多处理 6 个可疑区域，并限制额外处理预算。

```powershell
python -m pip install pyinstaller
python package.py
```

打包包含 OCR 模型、拼写词典和使用说明。生成的 exe 位于 `dist`。分发时不要包含个人 `config.json`。
