# 截图工具 · Screenshot Translator

一款 Windows 截图翻译工具：框选屏幕，识别并翻译文字，将译文显示在原文位置，方便阅读外文网页、软件界面和文档。当前版本 **2.0.0**。

## 主要功能

- 本地 OCR 与后台小幅纠偏，支持 DeepL 等在线翻译服务。
- 原位译文显示，按住空格查看原图；仅主动点击“提取文字”才打开文字面板。
- F3 贴图置顶，支持拖动、滚轮缩放、Ctrl+滚轮调整透明度。
- 窗口选择，画笔、矩形、箭头、文字及遮盖打码。
- 复制与保存截图，自定义截图快捷键和开机启动。
- 白底工具栏、深色图标、细边框与柔和阴影；关于窗口提供 GitHub 和离线使用说明入口。
- 11 种主流翻译语种、安装版与便携版、旧配置迁移。

## 2.0.0 多语言与发行方式

- 设置分为常规、翻译两页，可指定截图源语言和翻译目标语言。
- 翻译支持简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语。新安装默认译成简中，1.x 配置迁移后保留自动中英互译。
- 中英 OCR 保留 RapidOCR；其他指定源语言使用 Windows 对应 OCR 语言包。缺少语言包时明确提示，不偷偷切换识别语种。翻译语种支持不等于所有 OCR 语言包已内置。
- 标准版配置存入 `%LOCALAPPDATA%\ScreenshotTranslator`；便携版的配置和识别缓存集中在程序旁的 `data` 目录。默认截图保存位置仍可在设置中选择。
- 初次启动可迁移 exe 同目录的旧 `config.json`，保留原文件；旧文件位于其他目录时，设置 → 常规 → 导入旧版配置。已有新配置不会被旧文件反复覆盖。
- 使用目录式运行库，提供安装器与便携 ZIP。配置原子写入，发布包排除用户配置和缓存；版本信息、关于与文档统一更新。

## 下载与升级

- **推荐安装版**：运行 `ScreenshotTranslator-2.0.0-Setup.exe`，按当前用户安装，支持快捷方式和卸载。更新与卸载保留用户配置。
- **便携版**：完整解压 `ScreenshotTranslator-2.0.0-Portable.zip`，运行其中的 `ScreenshotTranslator.exe`。保留 `portable.flag` 和整个 `_internal` 目录，不要只移动 exe。
- 升级便携版时退出旧程序，将旧 `data` 目录复制到新目录。旧版根目录只有 `config.json` 的，复制到新版 exe 同目录，首次启动自动迁移。
- 如果此前配置放在桌面或其他位置，可在设置中主动导入；程序不会搜索整个电脑寻找密钥。
- 本版是标准版：保留本地 OCR，在线翻译需要网络；尚不包含真正的离线翻译引擎或新增视觉 AI 能力。

## 使用

- F1 框选截图，F2 全屏截图；快捷键可在设置中修改。
- 工具栏“翻译”完成 OCR、后台纠偏、翻译和原位排版；“复原”切换原图，不自动弹出文字面板。
- 在截图窗口按住空格临时查看原图。
- F3 或点击“贴图”，让截图或译文独立置顶。
- 文字面板提供原始识别、可编辑的复核结果、完整译文；支持逐块重译、恢复及复制。
- Enter 确认到剪贴板，Esc 取消，Ctrl+Z 撤销标注。
- 托盘右键 → **关于** → **使用说明**，打开应用内离线帮助。

详细操作见 [使用说明](USER_GUIDE.md)。文中的快捷键占位符会在应用内替换为当前设置。

## 翻译服务与配置

支持 DeepL、Azure、OpenAI 兼容大模型、百度、有道及 Google / MyMemory 备用链路。在设置中选择引擎、填入对应凭据并测试。

本地 OCR 及复核不上传截图。在线翻译发送识别文字，DeepL 还会收到当前截图的相关文字作为上下文。首选引擎失败时可能改用备用服务，界面会标明。

`config.json` 保存设置与密钥，**不应提交到版本库**。标准版与源码运行使用 `%LOCALAPPDATA%\ScreenshotTranslator\config.json`；便携版使用 `data\config.json`。设置 → 常规可查看并打开数据目录。本仓库与发布包不含个人密钥。

## 开发与打包

建议 Windows 10/11、Python 3.11–3.13。

```powershell
python -m pip install -r requirements.txt
python main.py
```

RapidOCR 首次准备模型可能需要网络，模型就绪后识别可离线运行。Windows OCR 是备用引擎，受系统语言包影响。本地复核默认开启，每次最多处理 6 个可疑区域，并限制额外处理预算。

```powershell
python -m pip install pyinstaller
python package.py --iscc "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

需安装 Inno Setup 编译器，可用 `--iscc` 指定路径或 `ISCC` 环境变量。只生成便携包可用 `python package.py --portable-only`。构建结果位于 `dist/v2.0.0`，打包脚本先对标准运行库和便携模式分别进行 EXE 自检，再生成 ZIP、安装器与 SHA256 校验文件。目录式运行库位于 `dist/ScreenshotTranslator`，保留 `_internal` 目录。
